# Emotion Recognition in DUUI

## Overview
Emotion recognition in videos has been around for some time, and various methods currently exist. In addition to pure video analysis, multimodal Large Language Models (LLMs) can also deliver good results in emotion recognition (e.g., Phi-4). 

## Project Objective
The primary task is to implement and evaluate emotion recognition components within the **DUUI** framework. 

Key responsibilities include:
* Utilizing existing models while also taking established methods into consideration.
* Working at the intersection of video, audio, and text-based emotion recognition.
* Developing methods to seamlessly implement and combine these different recognition types within DUUI.

## Topics & Technologies
This project touches on the following areas and technologies:
* **DUUI**
* **LLMs** (Large Language Models)
* **Python**
* **Transformers**
* **Libraries**
* **REST**
