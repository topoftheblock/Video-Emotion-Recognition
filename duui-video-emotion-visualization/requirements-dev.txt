# Run the suite with:
#
#   docker compose run --rm tests
#
# Version ranges are floor-and-ceiling. The floor is the version this project is
# actually built and tested against; the ceiling is the next major, so a new
# major cannot arrive silently and change the program under us. Phase 9 adds a
# lockfile on top for exact reproducibility.
